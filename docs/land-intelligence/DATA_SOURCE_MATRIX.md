# Data source matrix

**Colorado expansion, 2026-10-25:** [The statewide source inventory](COLORADO_STATE_DATA.md) tracks the state parcel identifiers, CDOT local road and bridge pilots, and DWR, ECMC, CPW and CWCB candidates. The CDOT adapters are implemented locally but remain unverified against live feature queries and official-viewer parcels. Empty results therefore report unknown coverage. No rights decision for CDOT reuse or new statewide data family has been made.

Audited 2026-10-24. **Configured** means a URL appears in code. **Metadata checked** means an official service metadata or agency documentation page was opened during this audit. **Query verified** would require a real spatial/record request and response checked against its schema and a known parcel; no provider is assigned that level here. Mocked tests verify code behavior only. Endpoint uptime, rate limits, county completeness, source refresh and license grants remain unverified unless stated. Most government endpoints appear free to access, but do not infer unrestricted commercial reuse from public access. Require a recorded license review before redistribution or bulk storage.

## Phase 1 access check, 2026-10-24

The official [Colorado parcel layer metadata](https://gis.colorado.gov/public/rest/services/Address_and_Parcel/Colorado_Public_Parcels/MapServer/0?f=pjson) was readable through the web source and advertises polygon geometry, query capability, GeoJSON output and a 2,000-record service maximum. A bounded parcel query to that layer could not be opened through the web source, and a direct request from this workspace returned “Unable to connect to the remote server.” Washington layer metadata could not be opened. [NRCS Soil Data Access documentation](https://sdmdataaccess.nrcs.usda.gov/WebServiceHelp.aspx) was readable. These checks do **not** establish a working real-parcel request for any provider. The Phase 1 fixture/query ledger and source-specific commercial/reuse permission review remain open; do not promote a configured integration to verified until those checks succeed.

### Rights and Phase 2 source check, 2026-10-24

- The [Colorado public parcels service description](https://gis.colorado.gov/public/rest/services/Address_and_Parcel/Colorado_Public_Parcels/MapServer) expressly allows commercial application use with State attribution and expressly forbids resale of the data. Use the service for cited parcel screening; do not package a bulk resale dataset. Its stated attribution should be included in application documentation with the actual access date. This is a source-specific decision, not a blanket grant for other Colorado layers.
- The [Boulder assessor download page](https://bouldercounty.gov/property-and-land/assessor/data-download/) lists the seven tables used by the importer and says they refresh daily at 4 a.m. The [county help manual](https://assets.bouldercounty.gov/wp-content/uploads/2017/02/ar-property-data-download-help.pdf) explains folio/account joins, multiple accounts, assessor valuation dates, permit limits and that the Sales table includes deeds that are not market sales. The county's [Open Data Catalog terms](https://bouldercounty.gov/government/open-data/terms-of-use/) grant reuse with attribution for catalog datasets, but the assessor download page does not clearly identify its CSVs as catalog datasets under those terms. Treat bulk redistribution and retention rights for these seven files as **unconfirmed** until the county confirms applicability. The importer now stages the snapshot in ignored, server-only `data/land-intelligence/boulder/`; the seven supplied CSVs were imported locally on 2026-10-25 into a 130,112-parcel compressed snapshot. A production deployment must package an approved snapshot at build time to expose county details.
- The [Boulder Recording Division](https://bouldercounty.gov/records/recording/) offers a public record search. The assessor CSV reception number can guide a user to a deed, but no stable record URL, machine-readable search API or parcel/account join has been verified. Keep it as a search link; do not label a recorded document independently verified.
- The configured Denver storm-main layer's official service metadata and query remain inaccessible from this environment. Authority, footprint, positional accuracy and reuse rights are **unverified**; its existing map output remains a screening reference, not a confirmed utility-owner pilot.

**Decision rule:** promote a candidate only after a real known-parcel request, schema/CRS/coverage check, source date, quota, rights, cost and error test are captured. Retain a service probe log with date and sample response outside any personal data. A single successful metadata request proves only metadata availability.
