## Phase 3 progress (2026-10-25)

**Colorado and sidebar continuation, 2026-10-25:** Map Inspection now puts owner, recorded sale price/date and value first, with explicit source and multi-account caveats. Its 12 subject areas and full property record share one open section; Boulder accounts and each account's values, deeds, buildings and permits use selectors/tabs to reduce scrolling while retaining full rows. The Colorado parcel detail now carries account, subdivision, block and lot when supplied. CDOT local road intersections and bridge/culvert points within 250 m have local adapters and focused mock tests. Official layer metadata was inspected, but live feature queries, source reuse rights, agency-viewer comparisons and browser interaction checks remain open. See [Colorado state data](COLORADO_STATE_DATA.md) for the prioritized inventory. This is progress within Phase 3, not a new phase or a claim of statewide completeness.

Phase 3 is the **last planned implementation phase**, and it is **in progress**. Map Inspection and the printable report now use all 12 requested subject areas with distinct semantic icons on screen. Each connected map source appears in exactly one area. Buildings, land, legal, and permits link back to the property record and explicitly describe missing source types. One deterministic combined observation reports only when both a complete FEMA flood result and a complete NWI wetland result contain a parcel-intersecting feature; the observation links both records and does not claim that the two polygons overlap. The general report cards now use separate leaf and factory icons for wetlands and regulated facilities.

**Coverage reality:** selectable statewide parcel boundaries are configured for CO, UT, WA, FL, NC and WI, subject to each provider's coverage and uptime. Boulder is the only locally loaded detailed assessor snapshot. Other U.S. areas can use the pin/line/area study tools, but cannot open a complete parcel inspection without a connected authoritative parcel polygon. Even inside those six states, the 12 areas are topic navigation, not a guarantee that every listed record type is searchable. Utility-owner lines, legal restrictions, approved plans, building footprints and several hazard families remain unconnected.

## Test and release gate for every adapter

One fixture for a true match, one neighboring false positive, one empty *within confirmed coverage*, one outside coverage, one schema/HTTP failure, one truncated response and one stale record. Verify raw-to-normalized attributes, geometry/CRS, original ID/link/date/accuracy, rights and cache behavior. Compare at least one real record against the agency viewer. Keep map toggle, print and current route contract regression tests. A feature is done only when its Map Inspection state is understandable with the provider offline.
